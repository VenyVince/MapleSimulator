# 메이플 레벨 시뮬레이터 MVP 기획안 (v1.0)

## 1. 프로젝트 개요

### 프로젝트명
메이플 레벨 시뮬레이터

### 목적
사용자가 현재 캐릭터의 레벨과 경험치, 반복적으로 수행하는 일간/주간 루틴을 설정하면 특정 날짜까지 달성 가능한 레벨과 경험치를 시뮬레이션하여 제공하는 서비스.



## 2. MVP 목표

### 포함 기능

- 현재 캐릭터 정보 입력
- 일간 루틴 설정
- 주간 루틴 설정
- 이벤트 재화 입력
- 사냥 경험치 계산
- 날짜별 레벨 시뮬레이션
- 결과 조회

### 제외 기능 (V2)

- 로그인(OAuth)
- 캐릭터 관리
- 루틴 저장
- 통계 기능
- 목표 레벨 달성 예상일 계산
- 이벤트 시스템
- 관리자 기능



## 3. 주요 기능

### 3.1 사용자 정보 입력

사용자가 직접 입력한다.

#### 입력 정보

- 현재 레벨
- 현재 경험치 (퍼센트 또는 절대값)
- 적용 중인 버닝 이벤트



### 3.2 일간 루틴

설정 가능한 항목

- 사냥
- 몬스터파크
- 일일 퀘스트



### 3.3 주간 루틴

설정 가능한 항목

- 에픽던전
- 익스트림 몬스터파크



### 3.4 이벤트 재화

사용자가 직접 입력한다.

- 성장의 비약
- 상급 EXP 쿠폰
- 베리류 티켓
- 기타 경험치 재화



## 4. 사냥 설정

### 입력 정보

- 사냥터
- 사냥 시간
- 도핑 종류 (버닝필드 포함)
- 6분당 몬스터 처치 수

#### 기본값

- 6분당 몬스터 처치 수는 해당 사냥터의 최대 마릿수를 기본값으로 사용한다.
- 사용자는 직접 수정할 수 있다.

### 계산 요소

- 몬스터 기본 경험치
- 사용자와 몬스터의 레벨 차이 보정
- 경험치 증가 도핑(합연산)
- 6분당 처치 수
- 총 사냥 시간

### 계산식

```
획득 경험치 =
몬스터 기본 경험치
× 레벨 차이 보정
× 경험치 증가율
× 처치 수
× 사냥 시간
```



## 5. 시뮬레이션

### 입력

- 시작 날짜
- 종료 날짜
- 현재 레벨
- 현재 경험치
- 일간 루틴
- 주간 루틴
- 이벤트 재화

### 처리 방식

- 경험치는 일 단위로 계산한다.
- 일일 컨텐츠는 매일 초기화된다.
- 주간 컨텐츠는 매주 목요일 초기화된다.

### 출력

- 날짜별 레벨
- 날짜별 경험치
- 누적 획득 경험치



## 6. 메인 화면

### 상단

- 이전날
- 현재 날짜
- 다음날
- 날짜 선택

### 중단
#### 사용자 정보

- 현재 레벨
- 현재 경험치
- 버닝 이벤트 선택
- 성장의 비약 입력
- 상급 EXP 쿠폰 입력
- 베리류 티켓 입력
- 기타 경험치 재화 입력

### 하단
#### 루틴

##### 일간 루틴

- 사냥
- 몬스터파크
- 일일 퀘스트

##### 주간 루틴

- 에픽던전
- 익스트림 몬스터파크

#### 결과

- 현재 레벨
- 현재 경험치
- 경험치 표시 방식
  - 퍼센트
  - 절대 경험치
