# 메이플 레벨 시뮬레이터 MVP 기획안 (v1.0)

## 1. 프로젝트 개요

### 프로젝트명
메이플 레벨 시뮬레이터

### 목적
사용자가 현재 캐릭터의 레벨과 경험치, 반복적으로 수행하는 일간/주간 루틴을 설정하면 특정 날짜까지 달성 가능한 레벨과 경험치를 시뮬레이션하여 제공하는 서비스.



## 2. MVP 목표

### 포함 기능

- 현재 캐릭터 정보 입력
- 일간 루틴 설정
- 주간 루틴 설정
- 이벤트 재화 입력
- 사냥 경험치 계산
- 날짜별 레벨 시뮬레이션
- 결과 조회

### 제외 기능 (V2)

- 로그인(OAuth)
- 캐릭터 관리
- 루틴 저장
- 통계 기능
- 목표 레벨 달성 예상일 계산
- 이벤트 시스템
- 관리자 기능



## 3. 주요 기능

### 3.1 사용자 정보 입력

사용자가 직접 입력한다.

#### 입력 정보

- 현재 레벨
- 현재 경험치 (퍼센트 또는 절대값)
- 적용 중인 버닝 이벤트



### 3.2 일간 루틴

설정 가능한 항목

- 사냥
- 몬스터파크
- 일일 퀘스트

#### 일간 루틴 정책

- 사냥 루틴은 단일 사냥터 기준으로 하루마다 반복한다.
- 사냥 도핑은 사냥 루틴 등록 시에만 입력받으며, 사냥 경험치 계산에만 적용한다.
- 몬스터파크와 일일 퀘스트는 사용자가 입력한 이벤트 추가 경험치 값을 루틴에 포함할 수 있다.



### 3.3 주간 루틴

설정 가능한 항목

- 에픽던전
- 익스트림 몬스터파크

#### 주간 루틴 정책

- 주간 컨텐츠 횟수는 매주 목요일에 초기화된다.
- 에픽던전과 익스트림 몬스터파크는 사용자가 직접 수행 날짜를 선택한다.
- 수행 날짜를 선택하지 않은 주간 컨텐츠는 시뮬레이션에 반영하지 않는다.
- 시작 주의 남은 주간 횟수는 자동으로 사용 처리하지 않고, 사용자가 선택한 날짜만 반영한다.
- 에픽던전과 익스트림 몬스터파크는 사용자가 입력한 이벤트 추가 경험치 값을 루틴에 포함할 수 있다.



### 3.4 이벤트 재화

사용자가 직접 입력한다.

- 성장의 비약
- 상급 EXP 쿠폰
- 베리류 티켓
- 기타 경험치 재화

#### 이벤트 재화 사용 정책

- 이벤트 재화는 사용자가 직접 설정한 날짜에만 사용된다.
- 하루 단위 시뮬레이션에서 사용자가 원하는 날짜에 재화를 기입하고 선택한다.
- 성장의 비약 획득 경험치는 `jsonData/other/growth_potion_delta.json`의 레벨별 경험치 획득량을 기준으로 계산한다.



## 4. 사냥 설정

### 입력 정보

- 사냥터
- 사냥 시간
- 도핑 종류 (버닝필드 포함)
- 6분당 몬스터 처치 수

#### 기본값

- 6분당 몬스터 처치 수는 해당 사냥터의 최대 마릿수를 기본값으로 사용한다.
- 사용자는 직접 수정할 수 있다.
- 사냥 루틴은 하나의 사냥터만 선택한다.
- 등록된 사냥 루틴은 매일 반복된다.

### 계산 요소

- 몬스터 기본 경험치
- 사용자와 몬스터의 레벨 차이 보정
- 경험치 증가 도핑(합연산)
- 6분당 처치 수
- 총 사냥 시간

### 계산식

```
획득 경험치 =
몬스터 기본 경험치
× 레벨 차이 보정
× (1 + 사냥 경험치 증가율)
× 처치 수
× 사냥 시간
```

도핑 경험치 증가는 합연산으로 계산하며 사냥 경험치에만 적용한다.



## 5. 시뮬레이션

### 입력

- 시작 날짜
- 종료 날짜
- 현재 레벨
- 현재 경험치
- 일간 루틴
- 주간 루틴
- 이벤트 재화

### 처리 방식

- 경험치는 일 단위로 계산한다.
- 일일 컨텐츠는 매일 초기화된다.
- 주간 컨텐츠는 매주 목요일 초기화된다.
- 주간 컨텐츠는 사용자가 선택한 수행 날짜에만 반영한다.
- 이벤트 재화는 사용자가 선택한 사용 날짜에만 반영한다.
- 몬스터파크, 익스트림 몬스터파크, 에픽던전, 일일 퀘스트는 기본 경험치에 비례한 이벤트 추가 경험치 입력값을 받을 수 있다.

### 계산 규칙

- 레벨업 후 남는 경험치는 다음 레벨로 이월한다.
- 경험치 100% 초과 입력은 잘못된 입력으로 처리한다.
- 경험치 100% 초과 입력 시 내부 절대 경험치는 해당 레벨의 필요 경험치 - 1로 보정한다.
- 경험치 100% 초과 입력 시 화면 표기는 99.9%로 표시한다.
- 버닝으로 여러 레벨업이 발생해도 잔여 경험치는 최종 표시 레벨로 이월한다.
- 성장의 비약, 소모 재화, 컨텐츠 경험치, 사냥 경험치로 레벨업이 발생하는 경우 모두 레벨업 이전의 절대 경험치에 획득 경험치를 더한 뒤 레벨업과 이월을 처리한다.

### 출력

- 날짜별 레벨
- 날짜별 경험치
- 누적 획득 경험치

## 7. 게임 데이터

JSON으로 관리한다.

- `jsonData/level_exp_table.json`: 레벨별 필요 경험치
- `jsonData/hunting/level_diff_multiplier.json`: 캐릭터와 몬스터 레벨 차이 보정
- `jsonData/hunting/exp_doping_summary.json`: 사냥 도핑 데이터
- `jsonData/hunting/map_monster/grindas_maps_index.json`: 사냥터 인덱스
- `jsonData/hunting/map_monster/grindas_maps_*.json`: 사냥터 및 몬스터 데이터
- `jsonData/routine/daily/monster_park.json`: 몬스터파크 데이터
- `jsonData/routine/daily/daily_quest.json`: 일일 퀘스트 데이터
- `jsonData/routine/weekly/epic_dungeon.json`: 에픽던전 데이터
- `jsonData/routine/weekly/extreme_monster_park_base_exp.json`: 익스트림 몬스터파크 기본 경험치 데이터
- `jsonData/other/growth_potion_delta.json`: 성장의 비약 레벨별 경험치 획득량
- `jsonData/other/exp_coupon.json`: EXP 쿠폰 데이터
- `jsonData/other/berry_ticket.json`: 베리류 티켓 데이터
